A mutex, or mutual exclusion object, is a synchronization mechanism used to ensure that only one thread can access a shared resource at a time. You would use a mutex when multiple threads need to access a shared resource, and you want to prevent race conditions or data corruption. For example, if multiple threads are updating a shared counter, a mutex ensures that only one thread can update the counter at a time, preventing incorrect values.
